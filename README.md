# ntypo

A fast, minimalist terminal typing test built with Bun and OpenTUI.

## Requirements

**Bun is required.** This CLI uses OpenTUI which depends on Bun's FFI.

Install Bun:

```bash
curl -fsSL https://bun.sh/install | bash
```

## Install

```bash
bun install ntypo -g
```

## Use

```bash
ntypo
```

## Local Development

### Prerequisites

- Bun (v1.3.1+ recommended)

### Setup

```bash
bun install
```

### Run

```bash
bun run index.ts
```
